# 관심분야 자동 리서치

관심 주제에 대해 웹사이트 3곳 이상을 브라우저로 탐색해 핵심 정보를 모으고,
정해진 포맷의 마크다운으로 정리한 뒤 노션에 공유하는 재사용 스킬.

## 절차

### 1. 주제·키워드 확인
- 사용자에게 **리서치 주제와 키워드**를 묻는다. (예: 국제뉴스 / 채용공고 / 맛집 / 부동산)
- 이미 주제를 말했으면 다시 묻지 말고 그대로 진행한다.
- 주제에 맞는 **출처 사이트 3곳 이상**을 정한다. (예: 국제뉴스 → BBC World, Al Jazeera, AP News)

### 2. 브라우저 MCP로 탐색 (3곳 이상)
- Playwright MCP(`browser_navigate` → `browser_snapshot`)로 각 사이트를 연다.
- 각 사이트에서 **오늘의 핵심 항목 3개 이상**(제목 + 한 줄 설명)을 추출한다.
- 스냅샷이 너무 크면(토큰 초과) 저장된 결과 파일을 `Grep`으로 `heading` 패턴만 뽑아 헤드라인을 추린다.
- 3개 사이트에 걸친 **공통 이슈/교차 테마**를 찾는다.

### 3. 정해진 포맷으로 md 작성
`research-{YYYY-MM-DD}.md` 파일을 만든다. **반드시 아래 포맷을 지킨다:**

```markdown
# {제목}

- **수집일:** {YYYY-MM-DD}
- **주제:** {주제}
- **출처:** {사이트1}, {사이트2}, {사이트3}

## 출처별 핵심
### 1) {사이트1} (링크)
- 핵심 3줄
### 2) {사이트2} (링크)
- 핵심 3줄
### 3) {사이트3} (링크)
- 핵심 3줄

## 한 줄 요약
> {전체를 관통하는 한 문장}

## 다음 액션
- [ ] {후속 조치 1}
- [ ] {후속 조치 2}
```

- 저장 위치는 사용자가 지정하지 않으면 현재 작업 폴더(또는 `week-5/news-research/`)에 둔다.

### 4. 노션에 공유
- Notion MCP(`notion-create-pages`)로 같은 내용을 페이지로 만든다.
- 제목은 md의 `#` 제목을, 아이콘은 주제에 맞는 이모지를 쓴다.
- 생성된 노션 페이지 URL을 사용자에게 알려준다.
- Notion MCP가 없으면 md 경로만 안내하고 건너뛴다.

## 재사용 팁
- 매주 같은 3개 출처로 다시 돌리면 "다음 액션"과 함께 **주간 변화 추이**를 비교할 수 있다.
- 주제/키워드만 바꾸면 채용공고·맛집·부동산 등 어떤 분야에도 그대로 적용된다.
