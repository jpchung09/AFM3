# 🎯 APP MISSION

## Project Name
**my_cafe — 평택 자매도시 탐색기 (Pyeongtaek Sister City Explorer)**

## Mission Statement
평택시가 어떤 해외 도시와 자매결연을 맺으면 좋을지, 도시의 산업·정체성에 근거해 후보를 추천하고 **세계지도 위에서 클릭 한 번으로 그 이유(공통점·보완점·미추천 사유)를 직관적으로 확인**할 수 있게 해주는 발표용 의사결정 지원 도구.

## Problem Statement
자매도시 선정은 보통 의례적·정치적으로 결정되어 "왜 이 도시인가"에 대한 산업적 근거가 약하다. 평택은 반도체(삼성 세계 최대 캠퍼스)·항만(자동차 수출·대중국 교역)·미군(캠프 험프리스)·자동차(KG모빌리티)·계획도시(고덕)라는 뚜렷한 정체성을 갖고 있음에도, 기존 교류가 중국·아시아에 편중되어 미국·서유럽 첨단산업 도시와의 접점이 비어 있다. 이 격차를 데이터와 근거로 메우는 추천이 필요하다.

## Target Users
- 평택시 국제교류 담당 공무원 / 정책 결정자
- 자매도시 선정 발표를 하는 발표자(사용자 본인)
- 시민 및 이해관계자 (근거를 쉽게 이해해야 하는 청중)

## App Type
- [x] Personal/Private Use (발표·의사결정 지원)
- [ ] Public/Commercial

## Core Features (v1)
1. **평택 도시 프로필** — 평택의 산업·정체성 요약(반도체/항만/미군/자동차/계획도시/농업)을 근거의 기준선으로 제시.
2. **세계지도 인터랙티브 UI** — 후보 도시를 지도 위 마커로 표시(나라·도시명 라벨), 클릭 시 상세 패널 표시.
3. **추천 근거 설명** — 각 도시별 공통점(왜 잘 맞는지)·보완점(무엇을 더해주는지)을 문장으로 제시.
4. **미추천 대조군** — 추천하지 않는 도시도 함께 표시하고 "왜 추천하지 않는지" 설명해 선택의 타당성을 강화.
5. **추천 등급/테마 시각화** — 최우선 추천/추천/신중/미추천을 색으로, 반도체·항만·미군·자동차 등 테마를 아이콘으로 구분.

## Anti-Scope (What this app will NOT do in v1)
- 실제 자매결연 체결·행정 처리 기능 없음 (추천·시각화까지만)
- 사용자 로그인/계정/권한 관리 없음
- 후보 도시를 사용자가 직접 CRUD 하는 관리자 화면 없음 (데이터는 리서치 기반으로 시드)
- 실시간 외부 API 연동(항만 통계 등) 없음 — 리서치 스냅샷 기반
