## 2. 평택은 어떤 도시인가 (임무 1 핵심)

평택 한 줄 정의 = **"세계 최대 반도체 생산기지 · 자동차 수출항 · 세계 최대 미군기지를 동시에 품은 수도권 최남단의 급성장 국제 산업도시"**

- 💠 **반도체**: 삼성전자 평택캠퍼스 — 세계 최대 단일 반도체 단지(누적 투자 180조+, P5 60조·2028 가동)
- ⚓ **항만**: 평택항 — 자동차 물동량 **전국 1위**, 대중국 교역 80%+
- 🚗 **자동차**: KG모빌리티 본사·공장 (완성차 생산 + 수출항이 한 도시에)
- 🎖️ **미군**: 캠프 험프리스 — **세계 최대 해외 미군기지**(약 4.5만 명, 미국형 도시)
- 🏙️ **계획도시**: 고덕국제신도시(수용 13.4만 명) — 급성장
- 🌾 **농업**: 슈퍼오닝(쌀·배) 도농복합

**전략적 공백**: 기존 우호교류도시 13곳은 **중국·아시아에 편중**(중국 7 등), **미국·서유럽 첨단 산업도시가 비어 있음** → 여기가 신규 자매도시의 기회.

## 3. 어떤 도시를 추천하나 (임무 2 핵심)

**추천 9곳 + 미추천 3곳(대조군)**. 모두 "평택과 만날 산업적 이유"가 분명한 도시.

### 🟢 최우선 추천 (미국·서유럽 공백 메우기)
- **신주(대만)** — TSMC 본사·신주과학단지 = 삼성 평택캠퍼스의 정확한 대칭
- **드레스덴(독일)** — 유럽 최대 '실리콘 작센' + EU 칩스법 네트워크
- **에인트호번(네덜란드)** — ASML 브레인포트 = 반도체 장비축 + 계획도시(고덕) 이중 매칭
- **힐즈버러(미국)** — 인텔 18A '실리콘 포레스트' = 한·미 반도체 동맹 상징
- **브레머하펜(독일)** — 유럽 최대 자동차 수출항(연 170만 대) = 평택항 자동차 1위 대칭

### 🔵 추천 (동맹·안보 서사)
- **킬린(미국)** — 포트 후드 군사도시 = 캠프 험프리스의 대칭점
- **요코스카(일본)** — 미 7함대 모항 = 미군기지+항만+제조 삼중 매칭
- **하이퐁(베트남)** — 빈패스트 품은 북부 항만·제조 성장도시 *(기존 베트남 우호도시 중복 확인 필요)*

### 🟡 신중 검토
- **기타큐슈(일본)** — 항만·제조 + 환경모델도시 전환 노하우(핵심 정체성 접점은 약함)

### ⚪ 미추천 (왜 빼는지도 설명 — 선택의 타당성 강화)
- **챈들러(미국)** — 힐즈버러와 주제 중복
- **볼프스부르크(독일)** — 단일기업 종속·내륙(항만 없음)
- **요코하마(일본)** — 규모 불균형·식상한 선택

## 4. 앱 데모 포인트 (발표 시연 시나리오)

1. **전체 지도**: 평택(빨간 펄스 마커)에서 추천 도시로 뻗은 연결선. 색 = 추천 등급, 아이콘 = 산업 테마.
2. **최우선 클릭**: 신주/힐즈버러 클릭 → 초록 패널에 **공통점·보완점**이 근거 문장으로 표시.
3. **미추천 클릭**: 챈들러/요코하마 클릭 → **⚠️ 추천하지 않는 이유** 표시 → "왜 이 도시가 아닌지"까지 설명.
4. **좌측 리스트**: 12곳을 등급·테마별로 한눈에, 클릭 시 지도가 해당 도시로 부드럽게 이동.

**데모 실행**: `cd week-6/my_cafe && npm install && node single.js` → 브라우저 `http://localhost:3100`

## 5. 기술 구성 (한 줄씩)

- **프론트**: `index.html` 하나 — React 18(CDN) + Tailwind + **Leaflet** 세계지도 (CARTO 타일).
- **백엔드**: `single.js` — Express. 정적 서빙 + `/api/cities` (Supabase 조회) + 최초 실행 시 후보 도시 자동 시드.
- **DB**: **Supabase PostgreSQL** `cafe_candidate_cities` (도시명·좌표·등급·테마·공통점·보완점·미추천사유).
- **아키텍처**: create_app 방법론의 **Option 1(Single-File)** 채택 — 빠른 구동·발표 최적.
- **MCP·에이전트 활용**: 리서치는 Claude 서브에이전트 2대 병렬 실행(평택 프로필 / 후보 추천), UI 검증은 Playwright(브라우저)로 실제 구동 확인.
